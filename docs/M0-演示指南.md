2. **看板 · 愿望单积累速率**：主数值为最近 4 周周均净增（发售后回落为负属正常现象，全期周均 +265、当前总量 11,947、脉冲日贡献 37% 新增）。图中**橙柱 = 脉冲周**：6 月新品节（周净增 +3,192）、发售前营销周、发售周。
3. **看板 · 页面转化率**：9.0% → 绿色「达标」（健康区间 5–12%）。注意口径面板：统计窗口自动从**首个购买日（发售日 2026-09-10）**起算——发售前转化率不适用，不编造 0%。

6. **脏数据演示**（F1/F5 预演）：「清空数据」后上传 `fixtures/dirty/` 里的文件：

7. 演示完毕点击「一键载入演示数据」恢复干净状态。

## 4. 三模板口径速览

| 模板 | 定义 | 公式 | 健康区间（经验值，非官方标准） | 数据源 |
|------|------|------|------|------|
| 愿望单积累速率 | 每周净增量及构成（自然 vs 脉冲） | 周净增 = Σ(新增−删单−购买移除−礼物移除)；脉冲日：当日新增 ≥ max(3×前28天中位数, 中位数+20) | 无固定区间（看趋势与脉冲占比） | 愿望单报告 |
| 页面转化率 | 访问→购买 | Σ购买 ÷ Σ访问（购买开放期，自首个购买日） | 5–12%；<5% 偏低 | 流量与转化报告 |
| 退款率 | 退款占毛销量比例 | Σ退款 ÷ Σ毛购买（未扣退款） | <10% 正常；10–15% 关注；>15% 警示 | 销售报告 |

口径依据：退款率公式与 Valve 官方定义逐字一致（官方原文："units returned in a given period divided by the number of units purchased in that period"）；愿望单字段语义与官方文档及 GetAppWishlistReporting API 一致。详见 [docs/steamworks-csv-formats.md](steamworks-csv-formats.md)。
