## 3. 演示脚本（约 10 分钟）

1. **注册 → 一键载入演示数据**（4 份 CSV + 演示评分快照，虚构游戏《星尘旅人》）。
2. **模板看板**：三阶段 12 卡（数值与口径详见中期指南第 3 节，已过双人审核）。
3. **AI 问数（新）**：顶部输入框——
   - 「最近愿望单涨得怎么样？」→ 意图解析区显示 `wishlist-accumulation` + 时间范围 + token 用量，下方是**与看板完全同构**的指标卡（同一计算函数、同一口径面板、同一教学卡片——D4 同源同构）；
   - 「最近30天页面转化率怎么样？」→ 时间范围被解析并过滤，参与行数随之变化（口径面板可见）；
   - 「预测下个月能卖多少份？」→ **正确拒绝并降级**：琥珀色提示 + 回落到模板看板，不出任何数值；
   - 「我的游戏和博德之门3比销量怎么样？」→ 同上（竞品数据不在范围）。
4. **降级路径**：不设置 API Key 时提问 → 「意图解析失败（缺 GAMESCOPE_GLM_API_KEY）→ 已降级」——报错可读、不编造。
5. **脏数据**：`fixtures/dirty/` 各文件（行级报错到列与行、缺列提示、缺口/重复/空值警告）。
6. **账号隔离**：第二账号登录后看板为空。
