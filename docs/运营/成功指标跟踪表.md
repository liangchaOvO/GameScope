# M2′ 成功指标跟踪表（发布后 4 周）

依据立项书 v2.0：替代原「≥3 人完成全流程」的内测成功指标。每周一结合 triage 更新一行。

口径定义：
- **试用数**：在线试用站匿名会话数（`data/trial-metrics.json` 的 sessions，去重会话）；
- **安装数**：可观测代理 = GitHub clone/fork 计数 + 本地模式用户自发反馈数（保守口径，仅记录有证据的）；
- **star**：仓库 star 数（每周日快照）；
- **issue 活跃度**：当周新增/关闭/评论数；
- **全流程完成率** = 「完成 3 次提问的会话」÷「完成上传的会话」（匿名计数 completed / uploads，仅在线站；本地部署无法统计，属预期）。

判断基线（与创始人对齐后可调整）：
- 发布帖发出后 4 周：试用会话 ≥50、全流程完成率 ≥30% 视为验证成功；
- star ≥30 且 ≥3 份外部指标模板贡献视为社区健康；
- 若完成率 <15%：优先排查「问 3 问」漏斗（是否 Provider 配置门槛过高）而非拉新。
