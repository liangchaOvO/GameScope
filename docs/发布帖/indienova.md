# 发布帖备稿 · indienova

> 标题：开源了一个面向独立开发者的 Steam 数据分析工具：上传 Steamworks CSV，看懂 12 个带口径的指标（AGPL，本地优先，BYOK）

---

各位好，我是一个独立开发者。做这个工具的起因很简单：Steamworks 后台给的是原始数字，而「愿望单转化 8% 到底是好是坏」这种问题，通用 BI 答不了——它们假设你会建模，但大多数独立开发者（包括我）需要的是**内嵌发行经验口径、并把口径摊开给你看**的工具。

**GameScope（AGPL-3.0 开源，本地优先，免费）**

- 上传你在 Steamworks 后台导出的 CSV（愿望单、流量与转化、销售、地区销售），自动识别格式、逐行校验，报错会精确到列和行；
- 12 个指标模板，覆盖发售前（愿望单健康）、发售期（首周表现）、长线运营（折扣脉冲、地区结构）：愿望单积累速率、删单率（>8% 预警）、页面转化率（5–12% 经验带）、退款率（>15% 警示）、Boxleiter 估算等；
- 每个结果都带**完整口径**：公式、参与计算的行数与时间范围、教学卡片（是什么/为什么这么算/健康区间/下一步问什么）。所有经验区间都标注「社区经验值，非 Valve 官方标准」；
- **AI 问数（BYOK，可选）**：用自然语言提问，LLM 只负责把问题解析成「指标 + 时间范围」，所有计算在本地代码执行——它没有机会编造数字。支持智谱 GLM、DeepSeek、Kimi、国家超算互联网 scnet.cn 的免费额度，以及**本机 Ollama 零成本方案**。不配置 Key 也完全可用（模板看板全功能）；
- 隐私：一切数据存在本机 SQLite，无遥测；商业敏感数据建议本地部署。

**获取**：GitHub（AGPL-3.0）：<你的仓库地址>，`npm install && npm run dev` 或 Docker 两行启动；内置一套虚构游戏的全周期演示数据，30 秒体验完整流程。

**想得到的反馈**：指标口径本身（尤其退款率与折扣脉冲系数的启发式）、bug、以及新指标模板贡献（有专门的 Issue 模板：定义/口径/健康区间出处/教学卡片）。

已知限制：真实 Steamworks 导出的列头回归仍在进行（当前按官方文档与社区资料构造，解析器为别名表设计，修正成本很低）；不做预测与竞品对比（刻意控制范围）。
