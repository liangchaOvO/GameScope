## 一、Blocking（必须修，3 条）

- **位置**：README.md L27、L30、L89；对照 package.json L7-9
- **问题**：L27 快速开始写「Node.js（Node 20+）」，同文件 L15 排查条目与 package.json `engines.node>=24` 均要求 ≥24；L30 与 L89 两处写「101 项测试」，实际 108（CHANGELOG L33 也写 108）。

- **依据**：package.json `"engines": { "node": ">=24" }`；实跑 `npm test` = 108 passed (8 files)。
- **方向**：L27 改为 Node 24+，两处 101 改 108（或改为动态表述「见 CI」）。

### B2. 「零遥测 vs 在线站匿名计数」未按验收口径表述（清单第 6 项不满足）
- **位置**：README.md L51（仅 Key 语境「不上传、不遥测」）；src/app/page.tsx L165-169（披露三段无计数说明）；docs/发布帖/indienova.md「隐私：一切数据存在本机 SQLite，无遥测」；docs/发布帖/r-gamedev-en.md「Privacy: everything runs locally … no telemetry」；docs/发布帖/v2ex.md「两种模式」条
- **问题**：代码在在线模式按会话持久化匿名计数到 `data/trial-metrics.json`（src/lib/trial.ts L100-118，sessions/uploads/asks/completed 四项），但没有任何用户可见文档写明此事。trial.ts L14 注释自称「本地模式保持零遥测（README 承诺不变）」——内部口径清楚，用户侧披露缺失。
- **影响**：产品核心卖点是「口径透明 + 不偷偷收集」；上线在线试用站后，任何人可从开源码发现该文件，与发布帖的绝对化「无遥测」表述冲突，反噬信任。清单第 6 项要求表述清楚「仅在线、次数无内容」——现状两条都不满足。
- **方向**：README（BYOK 或在线模式段）与三份发布帖各补一句：「软件本身零遥测；若以在线试用模式部署，站点会对匿名会话做功能计数（仅次数：会话/上传/提问/完成，无任何内容数据）」；page.tsx 披露段顺带补半句。

## 二、建议（值得考虑，4 条）

### S1. 过期试用项目的内存 Key 与计数器永不回收
- **位置**：src/lib/db/store.ts sweepExpiredTrials（L316-338，仅清 DB）；src/lib/trial.ts L72-86（memSettings Map）；clearMemorySettings 全仓仅 settings DELETE 路由调用（src/app/api/settings/route.ts L94）
- **问题与影响**：匿名项目 72h 过期被 sweep 后，其 Key 仍留在进程内存 Map 直至重启——与披露「随会话消失」存在措辞出入，且 sessions/uploads Set、asks Map 随会话数无界增长（长跑内存泄漏）。
- **建议**：sweepExpiredTrials 返回被清 projectId，trial 层据此 clearMemorySettings 并从 counters 移除对应条目。

### S2. clientIp 无条件信任 X-Forwarded-For；无该头时全站共享一个限速桶
- **位置**：src/lib/trial.ts L59-64
- **问题与影响**：直连（无反代）部署下：a) 伪造 XFF 即可绕过 IP 限速；b) 不带 XFF 时所有访客共用 `unknown` 桶 → 全站合计 20 问/小时，互相误伤。docs/github-发布清单.md 第 5 节只要求反代传 XFF，未警示禁止直连。
- **建议**：发布清单第 5 节补一句「必须置于可信反代之后，禁止 3101 直连公网」。

### S3. CHANGELOG 0.2.0 日期为未来日期
- **位置**：CHANGELOG.md L5「## [0.2.0] — 2026-10-31」
- **建议**：发布当天改为实际日期（今天已是 10-30）。

### S4. 门禁归档缺运行参数记录，且为旧评分口径
